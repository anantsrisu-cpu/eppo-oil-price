# นำเข้าราคาย้อนหลังรายแบรนด์ด้วยมือ (ไม่บังคับ)

สนพ. ไม่มีราคาย้อนหลังรายแบรนด์ของปี 2568 ให้ดึงอัตโนมัติ (มีเฉพาะ ปตท.)
ถ้ามีข้อมูลย้อนหลังของแบรนด์อื่น ใส่ไว้ในโฟลเดอร์นี้ ระบบจะรวมเข้า Dashboard ให้เองในรอบถัดไป

## ชื่อไฟล์
`<รหัสแบรนด์>_history.csv` เช่น `bcp_history.csv` (บางจาก), `shell_history.csv`, `caltex_history.csv`
รหัสแบรนด์: ptt, bcp, shell, caltex, irpc, pt, susco1, pure, susco2

## รูปแบบ (1 แถว = วันที่ราคาเปลี่ยน)
```
date,pds,ds,dsb20,gs95p,e85,e20,gh91,gh95
24/09/2569,50.05,41.44,36.44,49.29,30.88,34.94,39.57,39.94
```
- วันที่ใช้ได้ทั้ง `24/09/2569` (พ.ศ.), `24/09/2026` หรือ `2026-09-24`
- คอลัมน์ที่ไม่มีขาย เว้นว่างได้ · ลำดับคอลัมน์ `bcp_history.csv` เรียงตรงกับตารางหน้า
  "ราคาน้ำมันย้อนหลัง" ของบางจาก (ดีเซลพรีเมียม, ดีเซล B7, B20, แก๊สโซฮอล์ 95 พรีเมียม, E85, E20, 91, 95)
  จึงคัดลอกตารางจากเว็บไปวางใน Excel แล้ววางต่อจากแถวหัวตารางได้เลย
- บันทึกเป็น CSV (UTF-8) แล้วอัปโหลดทับไฟล์เดิมบน GitHub (Add file → Upload files → ลากไฟล์ไปวางในโฟลเดอร์ data/manual)
