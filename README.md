# ระบบข้อมูลราคาขายปลีกน้ำมันรายแบรนด์ (EPPO) อัตโนมัติ

ดึง **ราคาขายปลีกน้ำมันรายวันของ 10 แบรนด์** จากเว็บไซต์ สำนักงานนโยบายและแผนพลังงาน (สนพ./EPPO)
แบบอัตโนมัติทุกวัน **เวลา ~10:05 น.** (ไม่ต้องเปิดเว็บกด Generate) → เก็บเป็นฐานข้อมูล →
ทำ Pivot / SQL Query / Excel → แสดงผลเป็น **Dashboard ออนไลน์บน GitHub Pages**

แบรนด์: ปตท. · บางจาก · เชลล์ · เอสโซ่ · เชฟรอน (คาลเท็กซ์) · ไออาร์พีซี · พีทีจี (PT) · ซัสโก้ · เพียว · ซัสโก้ ดีลเลอร์

> 🚀 **ติดตั้งแบบไม่ต้องเขียนโค้ด:** เปิดไฟล์ `ติดตั้งระบบ-EPPO.html` ด้วย Chrome/Edge แล้วทำตาม 5 ขั้น (สร้างด้วย `python scripts/build_installer.py` → `dist/`)
>
> 📕 คู่มือฉบับเต็มพร้อมภาพ (PDF): [docs/คู่มือติดตั้งและใช้งาน.pdf](docs/คู่มือติดตั้งและใช้งาน.pdf) · 📘 วิธีติดตั้ง: [docs/SETUP.md](docs/SETUP.md) · 🛠️ เจอปัญหา/บั๊ก: [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) · 🔒 ความปลอดภัย: [SECURITY.md](SECURITY.md)

## 1. ภาพรวมการทำงาน

```
  ┌───────────────── GitHub (ตัวกลาง) ─────────────────────────────────────────┐
  │                                                                            │
  │  GitHub Actions (ตั้งเวลา 10:05 และ 11:35 น. ทุกวัน)                          │
  │   ├─ harden-runner: บล็อกอินเทอร์เน็ตทั้งหมด ยกเว้น eppo.go.th / github / pypi   │
  │   ├─ fetch_daily.py ──HTTPS GET──▶ www.eppo.go.th/wp-json/oil-api/v1/oil-prices │
  │   │                  (อ่านอย่างเดียว)   + ไฟล์ "โครงสร้างราคาน้ำมัน" รายวัน (.xlsx)   │
  │   ├─ ตรวจคุณภาพข้อมูล → บันทึก CSV + JSON ดิบ → commit เข้า repo                │
  │   └─ build: SQLite + Pivot + Excel + dashboard.json ──▶ GitHub Pages (static) │
  └────────────────────────────────────────────────────────────────────────────┘
        ▲ ผู้ใช้เปิดดู Dashboard / ดาวน์โหลด Excel, SQLite (อ่านอย่างเดียว)
        │ ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูลออนไลน์ ไม่มีรหัสผ่าน ให้แฮก
```

**แหล่งข้อมูลที่ใช้ (ตรวจสอบจริงเมื่อ 25 ก.ย. 2569)**

| ข้อมูล | ที่มา | ช่วงเวลา |
|---|---|---|
| ราคาขายปลีกรายแบรนด์ (10 แบรนด์ × 12 ชนิด) | JSON API เบื้องหลังหน้า "ราคาขายปลีกน้ำมัน" `…/wp-json/oil-api/v1/oil-prices` | ตั้งแต่วันที่เริ่มรันระบบ (25 ก.ย. 69) เป็นต้นไป ทุกวัน |
| ราคา ปตท. + ภาษี/กองทุน/ค่าการตลาด | ไฟล์ `pt-price-st-YYYY-M-D.xlsx` (โครงสร้างราคาน้ำมันรายวัน) | 2 ม.ค. 2568 → ปัจจุบัน (วันทำการ) |

> ⚠️ **ข้อจำกัดจากต้นทาง:** ปุ่มดาวน์โหลด/Generate ย้อนหลังรายแบรนด์บนเว็บ สนพ. (หลังย้ายเว็บ เม.ย. 2569)
> มีข้อมูลถึง **ก.ค. 2561 เท่านั้น** จึงไม่มีราคารายแบรนด์ย้อนหลังปี 2568 ให้ดึง
> ระบบจึงใช้ราคา ปตท. จากไฟล์โครงสร้างราคา (ราคาของผู้ค้าที่มีส่วนแบ่งตลาดสูงสุด) เป็นประวัติย้อนหลัง
> และเริ่มสะสมรายแบรนด์ครบทุกเจ้าตั้งแต่วันแรกที่ติดตั้ง — ยิ่งรันนาน ข้อมูลรายแบรนด์ยิ่งครบ
>
> **เอสโซ่:** API ของ สนพ. ยังส่งราคาที่มีผลตั้งแต่ 24 ก.ย. 2568 (ปั๊มเปลี่ยนเป็นบางจากแล้ว) และหน้าเว็บไม่แสดงคอลัมน์ ESSO
> ระบบตรวจเจออัตโนมัติ (ราคาเก่ากว่า 60 วัน) → เก็บไว้ในข้อมูลดิบ แต่ไม่นำไปคำนวณ/เปรียบเทียบ และขึ้นหมายเหตุใน Dashboard

## 3. ผลลัพธ์ที่ได้

| ผลลัพธ์ | อยู่ที่ |
|---|---|
| Dashboard ออนไลน์ (รายวัน/รายเดือน/รายปี, เลือกแบรนด์/ชนิด/ช่วงเวลา, ส่วนต่างเทียบ ปตท., โครงสร้างราคา, Pivot, ประวัติปรับราคา) | `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/` |
| Excel รายงาน (ชีท Latest, Monthly_Avg/Min/Max, Yearly_Avg, Daily_<ชนิด>, Price_Changes, Structure_PTT, **Data** เป็น Excel Table พร้อมทำ PivotTable เอง) | Dashboard → ดาวน์โหลด `oil_price_report.xlsx` |
| ฐานข้อมูล SQLite สำหรับ Query (มี view สำเร็จรูป `v_latest`, `v_monthly`, `v_yearly`, `v_changes`, `v_vs_ptt`) | Dashboard → ดาวน์โหลด `oil_prices.sqlite` |
| รายงานประจำวัน | `reports/latest.md` และหน้าสรุปของแต่ละรันใน GitHub Actions |

## 4. เริ่มใช้งานเร็ว (ทดลองบนเครื่องตัวเอง)

```bash
python -m pip install --require-hashes -r requirements.txt
python scripts/import_seed.py          # ใส่ข้อมูลตั้งต้น + build
python scripts/fetch_daily.py          # ดึงราคาวันนี้จาก EPPO (ต้องต่อเน็ต)
python scripts/run_query.py -f sql/queries.sql -n 2      # Pivot ราคาล่าสุด
python -m http.server 8000 --directory _site              # เปิด http://localhost:8000
```

ติดตั้งให้รันอัตโนมัติบน GitHub → ใช้ตัวติดตั้ง `ติดตั้งระบบ-EPPO.html` หรือดู **[docs/SETUP.md](docs/SETUP.md)**

## 5. นิยามข้อมูล (สำคัญเวลาอ่านตัวเลข)

- **ราคา** = ราคาขายปลีกมาตรฐาน กทม. นนทบุรี ปทุมธานี สมุทรปราการ (บาท/ลิตร) ยังไม่รวมภาษีบำรุงท้องถิ่น ตามที่ สนพ. ประกาศ
- **ตาราง daily** มีทุกวันปฏิทิน: วันที่ไม่มีข้อมูลใหม่ (เสาร์-อาทิตย์/วันหยุด/รันไม่สำเร็จ) ใช้ราคาล่าสุดต่อ ไม่เกิน 10 วัน (`source = carried_forward`)
- **ค่าเฉลี่ยรายเดือน/รายปี** = ค่าเฉลี่ยราคาทุกวันปฏิทินที่มีราคา (ถ่วงตามจำนวนวันที่ราคานั้นมีผล)
- **source** ในข้อมูล: `eppo_api` (ดึงวันนั้น) · `eppo_api_effective` (ย้อนไปถึงวันที่ราคามีผลตาม API) · `eppo_structure` / `seed_structure` (จากไฟล์โครงสร้างราคา) · `carried_forward`
