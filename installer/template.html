1. เตรียมตัว (2 นาที)

หน้านี้จะสร้างที่เก็บข้อมูล (repository) บน GitHub, ใส่โปรแกรม, ตั้งค่าความปลอดภัย, เปิดเว็บ Dashboard และสั่งดึงข้อมูลครั้งแรกให้ทั้งหมด

⚠ ถ้าข้ามข้อนี้จะเกิดปัญหาถ้าไม่ได้ล็อกอิน GitHub ไว้ ลิงก์สร้าง Token ในขั้นต่อไปจะพาไปหน้าล็อกอินแทน และถ้าไม่มี 2FA บางองค์กรจะไม่ยอมให้สร้าง Token

2. สร้างรหัส Token (กุญแจชั่วคราวให้หน้านี้ติดตั้งแทนคุณ)

  1. กดปุ่มสีน้ำเงินด้านล่าง → GitHub จะเปิดหน้า New personal access token (classic) ในแท็บใหม่ โดยกรอกไว้ให้แล้ว
  2. ช่อง Expiration เลือก 7 days
  3. ตรวจว่ามีเครื่องหมายถูกที่ repo และ workflow (ติ๊กไว้ให้แล้ว — ห้ามเอาออก)
  4. เลื่อนลงล่างสุด กด Generate token (สีเขียว)
  5. กดปุ่มคัดลอก 📋 ข้างรหัสที่ขึ้นต้นด้วย ghp_ แล้วกลับมาวางในช่องด้านล่าง
🔑 เปิดหน้าสร้าง Token บน GitHub
⚠ จุดที่ถ้าไม่ทำ ระบบจะติดตั้งไม่ผ่าน ถ้าไม่ได้ติ๊ก workflow ขั้น "อัปโหลดโปรแกรม" จะล้มเหลว (GitHub ไม่ยอมให้วางไฟล์ตั้งเวลาอัตโนมัติ) · รหัส Token จะแสดงครั้งเดียว ถ้าปิดหน้าไปก่อนคัดลอกต้องสร้างใหม่

🔒 รหัสนี้อยู่ในหน้านี้เท่านั้น ไม่ถูกบันทึกที่ไหน และส่งไปที่ api.github.com เท่านั้น · หลังติดตั้งเสร็จให้ลบทิ้ง (มีปุ่มพาไปลบในขั้นสุดท้าย)
